# 1. What is JavaScript ?

JavaScript (JS) is a programming language used to create interactive and dynamic web pages.

It is mainly used for:
- Website interactivity
- Dynamic content
- Form validation
- API handling
- DOM manipulation

---

# 2. Variables in JavaScript

Variables are containers used to store data values.

JavaScript provides three ways to declare variables:
- var
- let
- const

---

# 3. var, let & const

## var
- Can be re-declared
- Can be updated
- Function scoped
- Old way to declare variables

## let
- Cannot be re-declared
- Can be updated
- Block scoped

## const
- Cannot be re-declared
- Cannot be updated
- Block scoped
- Used for constant values
