# GitHub Profile Viewer 🚀

A simple and responsive GitHub Profile Viewer built using **HTML, CSS, and JavaScript**.

Users can search for any GitHub username and instantly view profile details such as avatar, bio, followers, following count, repositories, and profile link.

---

![GitHub Profile Viewer](images/project-screenshot.png)

---

## ✨ Features

- 🔍 Search GitHub users by username
- 👤 Display profile avatar
- 📝 Show user bio
- 👥 Display followers and following count
- 📂 Show public repositories count
- 🔗 Direct link to GitHub profile
- 🌙 Dark/Light theme toggle
- 📱 Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/GitHubProfile-Viewer.git
```

### Open Project

```bash
cd GitHubProfile-Viewer
```

Open `index.html` in your browser.

---

## 🔗 GitHub API Endpoint

```text
https://api.github.com/users/{username}
```

Example:

```text
https://api.github.com/users/octocat
```
