# 🎬 Movie Search App

A simple and responsive Movie Search Application built using **HTML**, **CSS**, and **JavaScript**. The app allows users to search for Studio Ghibli movies and view details such as the movie banner, title, release year, rating, and description.

## 📸 Screenshot

![Movie Search App Screenshot](./assets/Screenshot%202026-05-31%20102500.png)

## 🚀 Features

- Search movies by title
- Display movie banner image
- Show movie title
- Show release year
- Show movie rating
- Show movie description
- Responsive and clean UI
- Error handling for empty input and movie not found

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API

## ⚙️ How It Works

1. User enters a movie name.
2. Application fetches movie data from the Studio Ghibli API.
3. Movies are filtered based on the search input.
4. Matching movie information is displayed on the screen.
