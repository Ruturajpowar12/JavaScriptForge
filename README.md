# JavaScriptForge

JavaScriptForge is my personal JavaScript learning and development repository where I practice core concepts, modern ES6+ features, DOM manipulation, asynchronous JavaScript, and build mini projects.

This repository represents my journey to becoming a Full Stack Web Developer through consistent coding, problem-solving, and project building.

- `Building-Game/` — browser game project assets and logic.
