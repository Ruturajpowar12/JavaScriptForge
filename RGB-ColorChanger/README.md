# RGB Color Changer

A lightweight, interactive web-based tool that dynamically changes the background color of a webpage using HTML5 range sliders and JavaScript. Drag the sliders to explore and preview RGB values in real time.

## Preview

![RGB Color Changer Preview](./assets/Screenshot%202026-06-02%20154422.png)

## Features

- **Real-Time Updates:** Background color updates instantly as you drag the Red, Green, or Blue sliders.
- **Dynamic CSS Manipulation:** Uses JavaScript event listeners to inject live `rgb()` values into the DOM.
- **Text Readout:** Displays the exact generated CSS color format code at the bottom.
- **Full Range Exploration:** Supports the standard 0 to 255 RGB color space spectrum.
